# Обновление нативной части

Все файлы этого комплекта находятся внутри `app/src/main/cpp`. Никакие Gradle-файлы, AndroidManifest, workflow или файлы в корне репозитория изменять не требуется.

## Исправление ошибки `deps/raymob/display.c`

Сборка больше не подключает `deps/raymob` и не создаёт цель `raymoblib`. Игровой код использует только стандартный API raylib, поэтому зависимость от Android-дополнений raymob не нужна. Точка входа подключает `raylib.h` напрямую. Это убирает запрос к отсутствующему `deps/raymob/display.c` и не требует скачивать или копировать backend.

Существующий `app/src/main/cpp/deps/raylib` необходимо оставить на месте: это исходная зависимость проекта. Архив не содержит и не заменяет её.

## Применение

Распаковать архив с корнем репозитория, разрешив замену файлов. В архиве есть только `app/src/main/cpp/`. Другие части Android-проекта не затрагиваются. Не удалять существующий `deps/raylib`.

## Состав

- `main.cpp` — Android точка входа через raylib.
- `CMakeLists.txt` — сборка raylib и игровых исходников, NativeActivity glue, без зависимости `deps/raymob`.
- `game/` — игровой клиент, мир, генерация, предметы, способности и сетевой клиент.
- `tests/` — локальные тесты ядра, сетевого клиента и компиляции интерфейса с API-заглушкой.

## Проверки

Тесты находятся в `tests/`. Их можно собирать обычным CMake, а `tests/compile_ui_stub.sh` проверяет компиляцию UI и точки входа без реального Android SDK. Эти проверки не заменяют Android APK build.
